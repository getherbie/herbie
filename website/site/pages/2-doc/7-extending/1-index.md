# Extending

Herbie can be extended at several points in the application lifecycle.
You can add functionality in different ways, from PHP files in `site/extend` to plugins published as Composer packages.

- **[What can be extended](doc/extending/extension-points)** – the available extension points and ways to add them.
- **[Files in site/extend](doc/extending/files)** – add PHP files in `site/extend`.
- **[Register in index.php](doc/extending/bootstrap)** – register extensions in the `index.php` bootstrap file.
- **[Plugin class](doc/extending/plugin-class)** – bundle related extensions in a plugin class.
- **[Composer package](doc/extending/composer-package)** – publish a plugin as a Composer package.
- **[Example plugins](doc/extending/examples)** – six small plugins in ascending order of complexity.
